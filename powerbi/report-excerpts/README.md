# Illustrative report configuration excerpts

[Dashboard design](../../documentation/dashboard-design.md) | [Semantic model](../README.md)

These are **illustrative native-format excerpts**, not a complete Power BI report:

- [Revenue/profitability page settings](revenue-profitability-page.json): title, dimensions, display mode, and background configuration.
- [Marginal-analysis page settings](marginal-cost-revenue-page.json): title, dimensions, background, and hidden-page metadata.
- [Model reference](definition.pbir): the original relative byPath relationship to the sibling semantic-model folder, which resolves in this showcase.

The two page files were renamed for readability without changing their JSON content. Visual definitions, other page stubs/order metadata, report.json, and resource/theme packaging are not retained. These files demonstrate page/model configuration only; they cannot reproduce dashboard layout or be imported as a complete report. Existing design is shown by the reviewed screenshots, with financial qualifications.
